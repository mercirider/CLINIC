# Hospital Management System

A web-based Hospital Management System developed to manage hospital operations and patient-related information efficiently.

## Features

- Patient registration and management
- Doctor management
- Appointment management
- Patient records management
- Admin dashboard
- User authentication and login system
- Add, update, delete, and view records
- Database-driven hospital management
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- PHP
- MySQL

## Database

MySQL is used as the database to store and manage:

- Patient information
- Doctor information
- Appointment records
- User accounts
- Hospital-related data

## Installation

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
````

2. Move the project folder to your XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** from XAMPP.

4. Open **phpMyAdmin** and create a new database.

5. Import the project's SQL database file into phpMyAdmin.

6. Configure the database connection in the PHP configuration file.

7. Open the project in your browser:

```text
http://localhost/Hospital-Management-System/
```

## Project Purpose

The purpose of this project is to provide a simple and efficient web-based system for managing hospital operations, patient information, doctors, and appointments.

This project was developed as a learning and academic project to practice full-stack web development using PHP and MySQL.
